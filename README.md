# 词迹 Ciji

离线英语单词学习工具，支持双语例句、助记、笔记和词条修改。

## 下载最新版

**[点击下载词迹 v1.9.61](https://github.com/chenjiexu090/ciji/releases/tag/v1.9.61)**

- 安卓手机：下载 `ciji-v1.9.61.apk`，适用于 Android 7.0 及以上。
- 开发者：下载 `ciji-v1.9.61-source.zip`，这是对应源码；请勿误用 GitHub 自动生成的 Source code 包。
- 所有人均可免费下载、安装和使用，无需 GitHub 账号。

## 使用说明

下载 APK 后在安卓手机上打开安装。已有用户建议先备份学习数据，再覆盖安装。源码解压后打开 `app/index.html` 可体验网页界面，安卓构建说明见源码内文档。公开源码不包含原签名密钥，自行构建的 APK 无法直接覆盖原签名安装包。

## 本版进度与验证

v1.9.61 累计优化16500条助记，本批修订第16201—16500词。内容仍在持续校订。已核对199个网页资源与安装包逐字节一致，本次未进行安卓真机验证。
